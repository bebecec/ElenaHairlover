## PROTOCOLO DE GATE

Cada GATE debe ser aprobado por Walter antes de pasar a la siguiente fase.

```text
GATE ABIERTO   → Trabajo en progreso
GATE PASS      → Evidencia aceptada, se avanza
GATE PATCH     → Correcciones menores requeridas
GATE HOLD      → Bloqueado, requiere decisión de Walter
GATE CLOSED    → Baseline creada, fase sellada
```
