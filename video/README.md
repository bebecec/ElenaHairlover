# Carpeta de Videos

Coloca aquí tus clips MP4 con estos nombres exactos:

| Archivo             | Uso                                      | Duración recomendada |
|---------------------|------------------------------------------|----------------------|
| `hero.mp4`          | Vídeo de fondo del Hero (portada web)    | 6–15 seg             |
| `clip-facial.mp4`   | Clip de Estética Facial                  | 5–8 seg              |
| `clip-peluqueria.mp4` | Clip de Peluquería                     | 5–8 seg              |
| `clip-corporal.mp4` | Clip de Estética Corporal                | 5–8 seg              |
| `clip-unas.mp4`     | Clip de Uñas & Mirada                    | 5–8 seg              |

## Requisitos técnicos
- **Formato:** MP4 (codec H.264)
- **Sin sonido:** Grabados sin audio, o eliminar el audio antes de subir
- **Resolución:** 720p o 1080p
- **Tamaño máximo:** ~3 MB por clip (usa HandBrake para comprimir)
- **Hero:** preferiblemente horizontal (16:9)
- **Clips de sección:** preferiblemente vertical (9:16) para efecto "Reel"

## Herramienta gratuita para comprimir
HandBrake: https://handbrake.fr/
